Coin Rush effect assets

- bomb_spritesheet.rgba is a 4-frame, 64x16 atlas assembled left-to-right from the supplied Lit Bomb fire/16x16/frame_1.png through frame_4.png. The source frames and pack README are in this folder.
- plus_spritesheet.rgba is converted from the supplied Plus_spritesheet.png (640x1024; 5 columns x 8 rows of 128px frames).
- colored_hearts.rgba is converted from the supplied ColoredHeart_Red.png atlas. The HUD displays the first 16x16 red-heart tile; its supplied license is included here. The heart is integrated into the game HUD, not offered as a separate asset.

RGBA files are top-row-first, matching the game's existing raw sprite loader.
